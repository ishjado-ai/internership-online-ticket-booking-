# Smart Tiqet – Online Ticket Booking System

## Overview
Smart Tiqet is a web-based ticket booking system designed to simplify how people in Rwanda book transport and event tickets. Instead of traveling physically to bus stations or event venues, users can reserve tickets online anytime and from anywhere.

This project was developed using **HTML, CSS, and JavaScript** as a front-end solution to demonstrate digital transformation in ticket booking services.

## Problem Statement
In Rwanda, many people still experience challenges when booking tickets, such as:

- Long queues at bus stations and event venues
- Wasting time traveling just to check ticket availability
- Missing tickets because of late arrival
- Difficulty in choosing seats manually

Smart Tiqet was created to solve these challenges by providing a simple, fast, and interactive online booking platform.

## Features

### User Authentication
- User registration
- Secure login system
- Personal dashboard

### Transport Ticket Booking
Users can:

- Select departure location (e.g Nyabugogo Bus Station)
- Choose destination (Huye, Musanze, Rubavu, Ngarama)
- Select travel date
- Choose seats visually
- Confirm booking instantly

### Event Ticket Booking
Users can:

- View available events
- Choose event venues (e.g BK Arena, Amahoro Stadium)
- Select ticket type (VIP or Regular)
- Choose seats interactively
- Confirm event booking

### Digital Ticket Generation
After successful booking, the system automatically generates:

- Digital ticket
- Booking details
- QR code for ticket verification
